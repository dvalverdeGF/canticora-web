# Canticora web

Web app (PWA) instalable de [Canticora](https://canticora.com), el cancionero litúrgico que adapta
cada canto a la tonalidad y a la pantalla del coro.

* Aplicación: <https://dvalverdegf.github.io/canticora-web/>
* Web del producto: <https://canticora.com>
* Versión publicada: `1.1.4` (commit `f398d5b`)

Este repositorio **solo contiene artefactos generados**; no edites nada aquí a mano. Se publica con
`webApp/tools/deploy-web.sh` desde el repositorio de desarrollo, que compila con
`./gradlew :webApp:wasmJsBrowserDistribution`.
